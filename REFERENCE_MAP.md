Sprint 8A.1 audited wire conformance against the official spec: enforced `params._meta` placement, client capabilities (`io.modelcontextprotocol/clientCapabilities`), client info, routing headers (`Mcp-Method`, `Mcp-Name`), sessionless stateless lifecycle, connection-time DNS resolution/safe lookup to prevent DNS rebinding and private IP access, alternate IP encodings (octal, hex, dword, IPv4-mapped IPv6), streaming JSON/SSE memory consumption ceilings, and truthful authentication diagnostics. Zero external npm dependencies. | Specification references only; no external SDK code copied or pinned into dependencies; MIT license compatible. |
| Account Cryptography & Persistence Standards (RFC 7914 Scrypt, AES-256-GCM, SQLite) | REFERENCE_ONLY / BUILTIN | RFC 7914 (Scrypt), RFC 5869 (HKDF), NIST SP 800-38D (AES-GCM), Node `node:crypto`, `node:sqlite`; ADR-035, Sprint 8B | Evaluated password hashing algorithms (Argon2 vs Scrypt).
